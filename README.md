# Seasonality comparison of public transport demand forecasting models

Source code for the submitted manuscript entitled: Practical perspectives on machine learning interpretability for public transport demand forecasting

## Structure

- src: main source code containing models and data utilities
- 01_train_NP.ipynb: training NeuralProphet
- 01_train_XG.ipynb: training XGBoost
- 02_compare_effects.ipynb: comparison of daily seasonality components
